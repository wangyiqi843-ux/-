Brand Philosophy

日系極簡職人精神與足下哲學

「歩み（Ayumi）」在日文中象徵前進的腳步。我們相信，真正好的鞋子不應靠誇張的裝飾譁眾取寵，而是回歸身體本質，讓雙腳在漫長的通勤與生活中，找到如踏在細沙上的柔軟自由。

🍃

亞洲寬楦的溫柔包覆

大量亞洲人的前掌寬厚且足弓偏低，長時間穿著歐美窄楦尖頭鞋易導致拇趾外翻與足底筋膜炎。《歩み》精準重塑楦頭微弧曲率，給腳趾舒展伸張的天然空間。

☁️

如履雲端的減壓大底

選用生質低密度 EVA 減震複合材料，將每一步接觸地面的衝擊力均勻吸收轉化。重量僅約傳統膠底鞋的一半，徹底告別下班後小腿腫脹與沈重感。

📦

D2C 常溫超取的微型革命

捨棄實體百貨設櫃的高昂抽成與名牌溢價，直接透過 GitHub Pages 線上型錄與常溫 60 元超取直面消費者，將所有省下的成本投注於高級材料與親民定價。

Academic Framework SOP

行銷企劃 SOP 步驟 1 至 步驟 6 深度學理分析

嚴謹落實凌政文教授《行銷企劃》經典教材之五階段學理邏輯，從痛點發掘、PESTC 外部審視、內部假想敵防護、SWOT 因果推論到 SMART 與 STP/4P 全貌。

步驟 1：發掘痛點與創業動機

從「市售鞋版型困境」、「實體通路溢價門檻」與「極簡生活美學」三大構面提煉切入緣起。

階段 1：啟動與分析
01

歐美窄版型擠腳與足下健康危機

市售國際運動品牌多沿用歐美修長窄楦，亞洲人前掌骨架寬厚，長時間穿著通勤導致拇趾外翻、足底筋膜壓迫與水泡頻發，市面欠缺兼顧外觀美感與寬楦人體工學的鞋款。

02

實體門市抽成溢價與高庫存負擔

傳統鞋業受制於百貨櫃位 30%~45% 抽成與裝潢租金，售價嚴重灌水；微型創業者若貿然開店必受沉重庫存拖累。本案以「D2C 預購型錄 + 60 元常溫超商取貨」實現零店租成本。

03

快時尚膠底悶熱且缺乏日系極簡質感

平價快時尚鞋款多使用劣質回收塑料與刺鼻膠水，穿著半天即悶熱潮濕；而高價工匠鞋又厚重不便。市場迫切需要一雙能穿梭在通勤、校園與漫步時光的「侘寂極簡好鞋」。

步驟 2：外部總體環境 PESTC 深度分析

運用政治法律、經濟、社會文化、科技、綠色環保五大構面審視鞋履微型創業機遇。

外部趨勢盤點
P

政治與法律

經濟部標準檢驗局嚴格規範鞋類標示法規與塑化劑檢驗。本品牌堅持 100% 無毒環保無異味黏著劑，化法規規範為顧客信任護城河。

E

經濟環境

通膨壓力下青年族群消費更趨理性，重視「質價比」；千元左右親民定價搭配 60 元超取免排隊體驗，大幅提升下單轉化率。

S

社會文化

都會「Citywalk」與「慢生活運動」普及，年輕世代偏愛舒適鬆弛感穿搭，日系極簡無印風格深受大學生與白領族群青睞。

T

科技創新

超輕量生質 EVA 發泡大底與一體成型飛織技術成熟，小批量打樣與柔性製造門檻顯著降低，讓微型創業者能敏捷開發生產。

C

綠色環保

永續減塑意識高漲，選用天然可降解軟木鞋墊與極簡牛皮紙抽屜鞋盒，有效減少過度塑膠包裝，符合減碳消費風潮。

步驟 3：內部資源盤點與假想敵防護

評估創辦人個人資源限制，精準辨認市場假想敵，構築不對稱競爭之品牌護城河。

競爭護城河建構

🔍 創辦人內部資源評估

  • 優勢 (Strengths)：決策極致靈活、精通 AI 輔助行銷與 GitHub Pages 零伺服器靜態架站技術；完全無實體門市租金與人事包袱。
  • 劣勢 (Weaknesses)：啟動資金僅 3~5 萬元、一人獨立作業、初期採購無法具備大型連鎖品牌的開模議價優勢。

🛡️ 假想敵精準辨認與定位防護

  • 假想敵對象：大型量販快時尚合成膠底鞋（低價拼裝、透氣極差、楦頭過窄）與進口名牌過度溢價鞋款。
  • 我方防護之道：絕不落入低價價格戰陷阱，戰場移至「真實亞洲足型健康數據」與「無負擔赤足步態感」；採小批量預售限量釋出，以極致安心構築護城河。

步驟 4：SWOT 因果推論四象限四部曲綜合矩陣

嚴格按照 SO、WO、ST、WT 兩兩交叉碰撞因果行動推論，非單純條列事實。

四象限策略推論
SO 積極開拓策略 優勢 × 機會

發揮「亞洲加寬人體工學」與「常溫超取免店租」的成本結構優勢，搭乘都會 Citywalk 與日系侘寂風穿搭熱潮，透過社群發起「#一日萬步無痛挑戰」，迅速打入都會年輕學生與上班族社群。

WO 借力補強策略 劣勢 × 機會

針對初期資金有限與無法大量囤貨之劣勢，全面採用「線上預購意向登記（Pre-order）」模式，精準掌握鞋碼分布；將「小產能」反轉為「每批限量手工慢造、不撞鞋」的稀缺溢價。

ST 防禦轉化策略 優勢 × 威脅

面對同業低價仿冒與快時尚巨頭的價格傾銷，主動公開材料檢驗報告、鞋底耐磨減震系數及足弓支撐曲線；以「資訊全透明化」化競爭威脅為專業信任防線。

WT 避險聚焦策略 劣勢 × 威脅

初期嚴格管控款式數量，不盲目開發過多冷門鞋色，全心聚焦於「男女通用黑、白、米杏」三大經典明星單品，維持資金最高周轉率並避免死庫存積壓。

步驟 5：SMART 企劃目標與三超前瞻思維

設定 30 天內可量化驗證之期中 MVP 指標，並融入三超創新價值觀。

階段 2：目標與定位
S
具體 (Specific)：在 GitHub Pages 發布官方品牌線上型錄，完整上架針織寬楦、防潑水帆布、復古樂福三款鞋履。
M
可衡量 (Measurable)：上線 30 天內累計獲得 500 次有效瀏覽，並收集 50 份線上預購意向與鞋碼反饋。
A
可達成 (Achievable)：運用校園人際網絡、穿搭社團（Dcard/Threads）與日系生活圈擴散，指標穩健踏實。
R
相關性 (Relevant)：驗證寬楦日系極簡在平價市場的轉換率，為期末深入供應鏈落地量產決策提供客觀數據。
T
時限 (Time-bound)：於學期第八週前完成 GitHub 部署與公開連結測試，正式開放意向預約。

🚀 三超前瞻思維

1. 超前意識
在零庫存的前提下，搶先以 GitHub 靜態原型驗證消費者對楦頭與價格的真實意願，掌握第一手鞋碼大數據。
2. 超越常規
打破傳統鞋類不可更動架構，隨鞋標配「高足弓/扁平足」可抽換雙密度足弓支撐片，一雙鞋適配多元腳型。
3. 超越期望
隨鞋附贈日本檜木天然除臭木片香囊與「足部 3 分鐘穴位放鬆指引小卡」，傳遞有溫度的職人儀式感。

步驟 6：STP 市場定位與 4P 行銷組合

確立品牌價值主張與產品、價格、通路、推廣四大組合方案。

階段 3：方案設計與終點

🎯 STP 核心定位主張

市場區隔 (S)：依「行走時長」與「美學風格」區隔，鎖定每日步行超過 6,000 步且注重穿搭質感的族群。

目標市場 (T)：18~35 歲都會學生、久站零售族、通勤白領及極簡主義愛好者。

品牌定位宣言 (P)：「歩み AYUMI —— 每一步，都回到最放鬆的自己。」專注於亞洲寬楦與日系減壓美學的微型鞋履獨立品牌。

👞 產品 (Product) 規格

  • 明星單品 A：【雲感漫步】日系透氣針織寬楦休閒鞋（185g、微弧寬楦）
  • 明星單品 B：【雨日無憂】防潑水職人帆布鞋（奈米荷葉防潑、抓地止滑）
  • 風格選品 C：【侘寂微旅】可踩後跟復古軟皮樂福鞋（一秒穿脫、免綁鞋帶）

💰 價格 (Price) 策略

極致質價比：單雙售價落於 NT$ 1,180 ~ 1,480。早鳥預購意向享專屬特惠：

  • 任選兩雙折 NT$ 300，再享全台常溫超取免運費

🚚 通路 (Place) & 📣 推廣 (Promotion)

通路：個人 GitHub Pages 品牌入口，串接常溫超取（運費僅需 60 元），免實體抽成。

GitHub Pages Deployment Guide

期中報告成果：GitHub Pages 部署與提交指引

依據邱俊維博士操作手冊步驟，本單一檔案（index.html）完全無外部伺服器依賴，可直接上傳發布取得公開展示網址。

1

建立專案 Repo

登入 GitHub，右上角點「+」➔「New repository」，取名為 ayumi-shoes，勾選 Public 與 Add a README，按建立。

2

上傳 index.html

在專案頁面點擊「Add file」➔「Upload files」，將本單一檔案 index.html 拖曳至瀏覽器視窗中，點擊綠色「Commit changes」。

3

啟用 GitHub Pages

進入儲存庫頁面上方「Settings」➔ 左側點「Pages」，在 Branch 下將 None 改為 main，點擊右側「Save」。

4

取得成果公開網址

等待 1~2 分鐘重新整理，上方出現 https://[帳號].github.io/[Repo名稱]/，此網址即為期中作業提交之公開成果網址！
